# Workspace

Arborescence de travail. Chaque projet créé par HTB Launcher atterrit dans le
sous-dossier correspondant à son profil.

| Dossier | Contenu | Squelette créé |
|---|---|---|
| `htb/machines/<nom>` | Une machine HTB | `01-recon/ 02-exploit/ 03-loot/ notes.md` |
| `htb/academy/<module>` | Un module Academy | `01-recon/ 02-exploit/ 03-loot/ notes.md` |
| `ai/<projet>` | Entraînement, labs IA | `notebooks/ data/ models/ notes.md` |
| `reverse/<projet>` | Reverse, pwn, CTF | `bin/ scripts/ notes.md` |
| `dev/<projet>` | Projet de code | `git init` + `README.md` + `.gitignore` |
