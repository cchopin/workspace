OmniDigit Debug Console

Public QA notes for the OCR staging surface.

1. Observable Surface

OmniDigit accepts grayscale PNG CAPTCHAs made of six 28×28 digit tiles. The public bank on /omnidigit/ supplies the tiles shown on the main page. Staging only exposes the published example and layout metadata on this surface.

PropertyValue
FormatGrayscale PNG (single channel)
CAPTCHA dimensions168 × 28 pixels
Tile dimensions28 × 28 pixels
Tile count6
Public bank size30 tiles

Classifier details, training data, and acceptance thresholds are not published on this surface.

A clean accepted sample is published below. It passes normal verification and is useful for checking image layout, OCR behavior, and upload handling before you try anything more interesting.

2b. QA Validation Notes

Internal - retained from pre-deployment validation pass.

Verifier classifier was trained using a standard pipeline with canonical normalization and no proprietary augmentation. Anti-tampering validates per-tile L0 pixel distance against the public bank. It does not inspect perturbation provenance or gradient signatures.

Note: Classifier decision boundaries are consistent with independently trained instances on the same distribution. Robustness review pending.

3. Verification Path

POST /omnidigit/api/verify

Full verification endpoint. Admin access only succeeds when the submission stays close to the public bank and OCR resolves to the internal escalation pattern used by staging.

Live prediction diagnostics are not published on this surface. Use the example bundle to validate layout, then submit finished CAPTCHA candidates to the verifier.
